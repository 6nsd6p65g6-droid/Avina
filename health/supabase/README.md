# تشغيل خادم «أفينا» على Supabase

هذه الخطوات تتم **مرة واحدة فقط**. لا ترسل أي مفتاح سري (يبدأ بـ `sb_secret_` أو `sk-ant-`) في أي محادثة.

## 1) إنشاء قاعدة البيانات
1. افتح مشروعك في Supabase، ثم من القائمة الجانبية اختر **SQL Editor**، ثم **New query**.
2. انسخ محتوى الملف `schema.sql` كاملاً، والصقه، ثم اضغط **Run**.
3. يجب أن تظهر رسالة **Success**. تشغيله مرة ثانية لا يضر.

## 2) إعداد تسجيل الدخول بالبريد
1. **Authentication ← Sign In / Providers**: تأكد أن **Email** مفعّل.
2. **Authentication ← URL Configuration**:
   - **Site URL**: رابط التطبيق، مثلاً `https://6nsd6p65g6-droid.github.io/Avina/health/`
   - **Redirect URLs**: أضف الرابط نفسه.
3. (اختياري) **Authentication ← Emails**: يمكنك ترجمة رسائل التأكيد إلى العربية.

## 3) خادم الذكاء الاصطناعي
1. **Edge Functions ← Deploy a new function ← Via Editor**.
2. اكتب اسم الدالة: `ai` (بالحروف الصغيرة تماماً).
3. احذف الكود المكتوب مسبقاً، والصق محتوى الملف `functions/ai/index.ts`، ثم اضغط **Deploy**.
4. من إعدادات الدالة (**Details**) أوقف خيار **Verify JWT** (الدالة تتحقق من المستخدم بنفسها).
5. كرّر الخطوات لدالة ثانية باسم `pay` من الملف `functions/pay/index.ts`، وأوقف فيها **Verify JWT** أيضاً.
   هذه الدالة تفعّل الاشتراك تلقائياً بعد الدفع بالبطاقة عبر Stripe، ولا تلزم إن كنت ستراجع الطلبات يدوياً.

## 4) مفتاح الذكاء الاصطناعي
الخادم يعمل مع مزوّد مجاني أو مع Claude المدفوع، أو مع الاثنين معاً. يكفي مفتاح واحد.

**الخيار المجاني: Groq (بلا بطاقة مصرفية)**
1. أنشئ حساباً في **console.groq.com**، ومن **API Keys** أنشئ مفتاحاً (يبدأ بـ `gsk_`).
2. في Supabase: **Edge Functions ← Secrets ← Add new secret**:
   - الاسم: `GROQ_API_KEY`
   - القيمة: المفتاح.
3. احفظ. لا حاجة لأي إعداد آخر.

حدود الخطة المجانية في Groq تقريبية وتتغير، وهي مشتركة بين **كل** مستخدمي التطبيق:
- نحو 1000 طلب و200 ألف رمز يومياً للنموذج الأساسي، أي عشرات الأسئلة يومياً.
- إذا بلغ النموذج حدّه ينتقل الخادم تلقائياً إلى نموذج ثانٍ، ثم يطلب من المستخدم المحاولة لاحقاً.

**إعدادات اختيارية (أسرار غير سرية القيمة):**
- `AI_MODEL`: نموذج أو أكثر مفصولة بفواصل. الافتراضي `openai/gpt-oss-120b,qwen/qwen3.8-27b`.
- `AI_MODEL_BEST`: نموذج أقوى لخطة ألترا ولمقالات الموسوعة.
- `AI_MODEL_VISION`: نموذج يقرأ الصور، لميزة قراءة التحاليل. الافتراضي `qwen/qwen3.8-27b`.

أسماء النماذج في Groq تتغير. إذا توقفت ميزة فافحص الأسماء المتاحة لمفتاحك:
يرسل المدير طلباً إلى الدالة `ai` بـ `{"purpose":"provider_models"}` ليرى القائمة، وبـ `{"purpose":"provider_probe","model":"اسم النموذج"}` ليجرّب نموذجاً.
- `AI_BASE_URL`: لاستخدام مزوّد آخر متوافق مع OpenAI (مثل OpenRouter أو Cerebras) مع `AI_API_KEY`.

**الخيار المدفوع: Claude (أدق، ويناسب خطة ألترا)**
1. من **console.anthropic.com** أنشئ مفتاح API (يبدأ بـ `sk-ant-`).
2. أضفه في الأسرار باسم `ANTHROPIC_API_KEY`.
3. عند وجوده تُخدَم به الخطط التي نموذجها `claude-*` في جدول `plans`، وتُكتب به مقالات الموسوعة.

إن غيّرت المزوّد فحدّث اسمه في `privacy.html`، وتأكد أن شروطه لا تستخدم بيانات المستخدمين للتدريب.

## 5) اجعل نفسك مديراً
1. افتح التطبيق وأنشئ حسابك من صفحة «ملفي».
2. في **SQL Editor** شغّل هذا السطر بعد وضع بريدك:
   ```sql
   update public.profiles set role = 'admin' where email = 'بريدك@example.com';
   ```
3. أعد فتح التطبيق، فيظهر لك زر **لوحة التحكم** في «ملفي».

## 6) من لوحة التحكم
- **الإعدادات**: سعر الدولار بالدينار، ونسبة زيادة الكروت (20%)، وبيانات حسابك المصرفي، ورقم الدعم.
- **الموسوعة**: اضغط «اكتب المقالات الناقصة» ليجهز التطبيق مكتبة من 114 مقالة لكل المستخدمين (حوالي 8 دولارات مرة واحدة).
- **الطلبات**: راجع الحوالات والكروت، واضغط «قبول وتفعيل» أو «رفض».
- **الدفع خارج ليبيا** (في الإعدادات):
  - رابط PayPal مثل `https://paypal.me/اسمك/{amount}USD`.
  - روابط الدفع بالبطاقة بصيغة JSON لكل خطة ومدة، مثل `{"pro:1":"https://buy.stripe.com/...?client_reference_id={ref}&prefilled_email={email}"}`.
  - إن تركتها فارغة يُسجَّل الطلب وترسل للمشترك رابط الدفع بالبريد بنفسك.

## التفعيل التلقائي بعد الدفع بالبطاقة (اختياري، Stripe)
1. **Edge Functions ← Secrets**: أضف `STRIPE_WEBHOOK_SECRET` (يبدأ بـ `whsec_`).
2. في Stripe ← Developers ← Webhooks:
   - أضف الرابط `https://<مشروعك>.supabase.co/functions/v1/pay`.
   - اختر حدث `checkout.session.completed`.
3. اجعل كل رابط دفع يحمل `client_reference_id={ref}`. يُفعَّل الاشتراك فور الدفع إذا لم يقل المبلغ عن قيمة الطلب.

## حذف الحسابات
يحذف المستخدم حسابه من «ملفي ← حذف الحساب». تحذف الدالة `ai` عندها:
- إيصالاته من التخزين.
- حسابه، فتُحذف معه تلقائياً بياناته الصحية وطلباته واشتراكه.

## تعديل الخطط والأسعار
من **Table Editor ← plans** يمكنك تغيير السعر، وعدد الأسئلة اليومية `daily_ai`، والنموذج `model`.
مع المزوّد المجاني يُتجاهل اسم نموذج Claude ويُستعمل `AI_MODEL`، ويمكنك أيضاً كتابة اسم نموذج المزوّد مباشرة في `model`.
نماذج Claude:
- `claude-haiku-5-5`: الأرخص جداً (حوالي دولار لكل 1000 سؤال).
- `claude-sonnet-5-5`: متوسط.
- `claude-opus-5-5`: الأقوى والأدق (حوالي 0.03 إلى 0.06 دولار للسؤال).

## الإعداد التلقائي (بدل الخطوات 1 و2 و3 و4 و5)
إذا أضفت `SUPABASE_ACCESS_TOKEN` و`ANTHROPIC_API_KEY` إلى متغيرات البيئة، يمكن تشغيل:
```bash
ADMIN_EMAIL=بريدك@example.com bash health/supabase/deploy.sh
```
فينشئ قاعدة البيانات، ويضبط تسجيل الدخول، وينشر خادم الذكاء الاصطناعي، ويضع مفتاح Claude، ويجعل هذا البريد مديراً (حتى لو أنشأت حسابك بعد التشغيل).

## إذا لم يعمل الطبيب الذكي
- **Edge Functions ← ai ← Logs** تعرض سبب الخطأ.
- إذا ظهر خطأ عن المفتاح السري لقاعدة البيانات: أضف Secret باسم `SB_SECRET_KEY` وقيمته المفتاح السري من **Project Settings ← API Keys** (يبدأ بـ `sb_secret_`).
- تأكد أن رصيدك في console.anthropic.com أكبر من صفر.
